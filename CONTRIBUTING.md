# Contributing

Use this public repository's Issues for reproducibility problems, questions and concrete evaluation use cases. Small documentation or verifier improvements can be proposed in a pull request.

For a reproduction report, include the public commit, Python/platform version, exact command, expected result, actual result and minimal sanitized output. Distinguish a verifier failure from a scientific disagreement. Never post credentials, private participant data or withheld confirmation answers.

For a use case, explain the decision you need to make, your existing test, the failure it misses and what result would change your decision. Read the limits in README.md before proposing a stronger claim.

Keep the archived experiments and their provenance intact. Propose new studies separately, recording protocol changes and all allocated attempts, including failures. New seeds from the same disclosed family are not independent new-family confirmation.

The prospective pilot is described in docs/INDEPENDENT_PROCEDURE_PILOT.md. Its freeze worksheet must be completed before a confirmation trial. No paid model calls are required to contribute or run the supplied reference checks.

Contributions are subject to the project's Apache-2.0 license. Sponsorship is optional and does not influence review or scientific conclusions. A response time or feature delivery is not guaranteed.
